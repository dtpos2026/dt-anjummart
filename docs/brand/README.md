## Rang kaise badlein

* **Canva:** Upload par SVG file dalein, logo par click karein, upar "Colors" se rang badlein. PDF Canva mein aksar ek tasveer ban kar khulta hai, is liye Canva ke liye SVG istemal karein.
* **Illustrator, Affinity, Inkscape, Figma:** SVG ya PDF dono khulte hain; shapes vector hain.
* File ke andar teen hisse (layers/groups) hain: `background` (profile templates mein), `logo-text-and-dark-shapes` (A ka kaala hissa, "Anjum" ke huroof, pahiye) aur `logo-gold` (sunehri hissa, gradient ke saath). Gold ka gradient `gold-gradient` mein hai; sada rang chahiye to us hisse ka fill ek rang kar dein.
* Template mein background ka rang `background` rectangle ka fill badal kar badlein. Logo gol crop mein kata na jaye is liye wo darmiyan mein chhota rakha gaya hai.

## Dhyan dein

Ye vectors store ki original logo tasveer (360 pixel) se trace kiye gaye hain. Normal istemal (profile, post, ads) mein saaf aur tez hain, lekin bohat bade banner par kinaron par chhoti si na-hamwari ho sakti hai. Agar aap ke paas original logo ki asli vector file (AI, SVG, EPS) ya bari PNG ho to wahi master banegi.
