assistant publish policies, so paste the final text yourself in **Settings → Policies** (each box has a
"Create from template" button that fills a standard version; edit it with the answers below).

Items in **[brackets]** are decisions only the store owner can make. Nothing below should be published until every
bracket is answered, because policy text is a commitment to customers (and Meta/Google ads review the pages).
