# Meta ads pack (Facebook / Instagram)

Creatives, captions and the setup guide for the first Meta campaign (WhatsApp message ads, then Shop Now ads).

* `make_ads_pack.py <cutouts> <perfume photos> <out>` writes the HTML pages and the caption files; `render.mjs <out>` renders them
  to JPG (feed 1080 x 1350 and story 1080 x 1920). The transparent product cut-outs (`cut-01.png` to `cut-12.png`, see
  `docs/catalog/art`) are not in the repository; the perfume photos are in `docs/catalog/art/perfume-photos`.
* `meta-ads-guide.html` is the Roman Urdu guide (printed to PDF in the zip); `captions/` holds the captions and ad fields;
  `WhatsApp-Quick-Replies.txt` and `Product-Links.txt` are for the daily WhatsApp work.
* The pictures use only store facts (prices, Free Delivery All Pakistan, Cash on Delivery). No discounts, urgency, ratings or
  authenticity claims. Mention the Advance Cash Payment discount only after the Shopify payment method is set up and tested.
