# 11.11 Sale branding (theme feature, switched off until the real discount exists)

What it adds (all from Theme settings, **11.11 Sale**; nothing shows while "Show the 11.11 Sale" is unticked):

| Part | Where | Notes |
| --- | --- | --- |
| Strip with countdown | Top of every page, above the announcement bar | Shimmer, pulsing "11.11 SALE" badge, offer line, "Ends in 2d 03h 04m 02s", link to the sale. On phones it wraps to two slim lines. |
| Animated banner | First section of the home page (`sections/sale-hero.liquid`, listed first in `templates/index.json`) | Big gold "11.11" with a moving shine, red SALE ribbon, rotating light rays, falling confetti, twinkling stars, four countdown boxes (seconds tick), button and an optional code chip with a Copy button. |
| Card tag | A small gold "11.11" tag on every in-stock product card | Can be switched off separately. |
| Ending | Server-side after the end date, and client-side while a page is open | Everything disappears by itself at the end time; nothing is left behind. |

Settings: **Show the 11.11 Sale**, **Offer (one line)**, small heading, small line under the banner, **Starts at** (optional), **Ends at**,
**Discount code** (optional), button label and link, and three switches (strip, card tags, confetti and shine). Dates are text in
Pakistan time, for example `2026-11-11T23:59:59+05:00`. With a start date in the future the banner says **Starts in** and the card
tags stay hidden until it begins. Visitors who prefer reduced motion never see any animation. In the theme editor a switched-off
sale shows a preview note.

## Rules we follow
* Switch it on only when the real discount exists in Shopify (Discounts) and its end date equals "Ends at". The countdown is the
  real deadline; do not set an end date the discount does not have.
* The Offer line must say exactly what the shopper gets (for example "11% off everything"). No made-up claims.

## The Shopify side (owner decision, needs the offer)
1. Discounts, create the offer (automatic discount or a code) with the same start and end time.
2. The existing code `ADVANCE499` does **not** combine with other discounts. If shoppers should get both the sale and the Advance
   Rs. 499, set both discounts to combine (Discounts, the discount, Combinations).
3. Theme settings, 11.11 Sale: tick the switch, type the offer, set the dates (and the code if there is one), Save.
